# Проверка внешнего IP на признаки прокси

**Видео №16** канала «ByteAutomate | Код и AI» — https://t.me/ByteAutomate_AI.

Проверяет репутацию внешнего IP (DNSBL) и типичные порты прокси на вашем компьютере.

## Что нужно

- Python 3.9+ (сторонние пакеты не нужны)

## Быстрый запуск

1. Windows: дважды щёлкните `start_checker.bat`.
2. Любая система: `python check_proxy_ip.py`.
3. Свой адрес без запроса к ipify: `python check_proxy_ip.py --ip ВАШ_АДРЕС`.
4. Прочитайте результат по `Инструкция.txt`.

## Состав

- `check_proxy_ip.py`
- `requirements.txt`
- `start_checker.bat`
- `Инструкция.txt`

Подробная пошаговая инструкция и ограничения — в `Инструкция.txt`.

## Важно

- Набор даётся как есть, без гарантий: сначала проверьте на тестовых данных и сделайте копию своих.
- Токены, ключи и пароли в репозиторий не входят — подставляйте свои и не публикуйте их.
