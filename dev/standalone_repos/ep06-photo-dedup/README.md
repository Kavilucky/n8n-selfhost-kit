# Поиск дубликатов фото pHash

**Видео №06** канала «ByteAutomate | Код и AI» — https://t.me/ByteAutomate_AI.

Находит похожие и дублирующиеся фото по перцептивному хешу, с режимом проверки и откатом.

## Что нужно

- Windows, Python 3.9+
- Интернет при первом запуске (ставятся пакеты)

## Быстрый запуск

1. Распакуйте ZIP-архив в обычную папку.
2. Сначала проверьте на копии: `find_duplicates.bat "D:\Фото_копия" --dry-run`.
3. Или перетащите папку с фото на `find_duplicates.bat`.
4. Откат: `find_duplicates.bat "путь" --undo`.

## Состав

- `find_duplicates.bat`
- `find_duplicates.py`
- `Инструкция.txt`

Подробная пошаговая инструкция и ограничения — в `Инструкция.txt`.

## Важно

- Набор даётся как есть, без гарантий: сначала проверьте на тестовых данных и сделайте копию своих.
- Токены, ключи и пароли в репозиторий не входят — подставляйте свои и не публикуйте их.
