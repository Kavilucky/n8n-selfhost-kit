# Голосовой ассистент в автомобиле CarPlay

**Видео №05** канала «ByteAutomate | Код и AI» — https://t.me/ByteAutomate_AI.

Шаблон n8n: голосовое сообщение в Telegram → расшифровка → задачи/встречи через Ollama.

## Что нужно

- Работающий n8n (см. ролик 01)
- Ollama с моделью `qwen2.5:3b`
- Сервис расшифровки и озвучки (адреса в шаблоне)
- Telegram-бот от @BotFather

## Быстрый запуск

1. Поднимите Ollama и скачайте модель (команды в `Инструкция.txt`).
2. В n8n: Workflows → Import from File → `carplay_assistant_n8n.json`.
3. Создайте свои Credentials (Telegram, при необходимости Notion/Google).
4. Проверьте адреса сервисов в узлах HTTP Request.
5. Запустите вручную, отправьте боту голосовое и проверьте результат.

## Состав

- `carplay_assistant_n8n.json`
- `Инструкция.txt`

Подробная пошаговая инструкция и ограничения — в `Инструкция.txt`.

## Важно

- Набор даётся как есть, без гарантий: сначала проверьте на тестовых данных и сделайте копию своих.
- Токены, ключи и пароли в репозиторий не входят — подставляйте свои и не публикуйте их.
