# Хранилище «Второй мозг» (шаблон)

Откройте эту папку в Obsidian как хранилище (Open folder as vault).

- `raw_inbox/` сюда скрипт кладёт скачанные голосовые (OGG) и откуда берёт их для расшифровки.
- `processed_notes/` готовые заметки Markdown с метаданными (frontmatter): дата, время, теги, источник, срок.
- `templates/voice_note.md` шаблон заметки; скрипт подставляет в него значения.

Заметки лежат в обычных файлах на вашем диске. Сделайте вторую копию хранилища на внешний диск (правило 3-2-1).
