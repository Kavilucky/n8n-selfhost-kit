# Проверка пароля на утечку без отправки пароля

**Видео №12** канала «ByteAutomate | Код и AI» — https://t.me/ByteAutomate_AI.

Проверка по Pwned Passwords с k-анонимностью: на сервис уходят только 5 символов SHA-1.

## Что нужно

- Python 3 (сторонние пакеты не нужны)

## Быстрый запуск

1. Распакуйте архив (или `git clone`).
2. Запуск: `python pwned_check.py` (Windows: `py`, Linux/macOS: `python3`).
3. Введите пароль (ввод скрыт).
4. Список паролей: `python pwned_check.py --file пароли.txt`.
5. Прочитайте `Чеклист_цифровой_гигиены.txt`.

## Состав

- `pwned_check.py`
- `Инструкция.txt`
- `Чеклист_цифровой_гигиены.txt`

Подробная пошаговая инструкция и ограничения — в `Инструкция.txt`.

## Важно

- Набор даётся как есть, без гарантий: сначала проверьте на тестовых данных и сделайте копию своих.
- Токены, ключи и пароли в репозиторий не входят — подставляйте свои и не публикуйте их.
