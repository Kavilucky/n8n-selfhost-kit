# Автобэкап данных по правилу 3-2-1

**Видео №09** канала «ByteAutomate | Код и AI» — https://t.me/ByteAutomate_AI.

Скрипты резервного копирования (Kopia/Restic) для Windows и Linux с проверкой и тестовой папкой.

## Что нужно

- Kopia или Restic
- Файл с паролем репозитория
- Внешний диск или второе хранилище

## Быстрый запуск

1. Откройте `backup_config.cmd` (Windows) или `backup_config.sh` (Linux) и впишите свои пути.
2. Проверьте на `Тестовая_папка`.
3. Запуск: `backup_windows.bat` / `./backup_linux.sh`.
4. Проверка: `backup_windows.bat verify` / `./backup_linux.sh verify`.
5. Автозапуск: `schtasks` (Windows) или `cron` (Linux), примеры в `Инструкция.txt`.

## Состав

- `backup_config.cmd`
- `backup_config.sh`
- `backup_linux.sh`
- `backup_windows.bat`
- `exclude.txt`
- `Инструкция.txt`
- `Тестовая_папка/Документы/договор_пример.txt`
- `Тестовая_папка/Документы/заметки_пример.txt`
- `Тестовая_папка/Документы/черновик.tmp`
- `Тестовая_папка/ПРОЧИТАЙ.txt`

Подробная пошаговая инструкция и ограничения — в `Инструкция.txt`.

## Важно

- Набор даётся как есть, без гарантий: сначала проверьте на тестовых данных и сделайте копию своих.
- Токены, ключи и пароли в репозиторий не входят — подставляйте свои и не публикуйте их.
