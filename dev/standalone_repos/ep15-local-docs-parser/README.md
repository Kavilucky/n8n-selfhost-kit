# Локальный парсер первички и актов без утечки в облако

**Видео №15** канала «ByteAutomate | Код и AI» — https://t.me/ByteAutomate_AI.

Читает PDF-акты и собирает реестр в Excel полностью локально (сеть заблокирована самим скриптом).

## Что нужно

- Windows 10/11, Python 3.9+
- Интернет один раз для установки пакетов
- Опционально: Ollama + `qwen2.5:3b`

## Быстрый запуск

1. Распакуйте ZIP-архив в обычную папку.
2. Проверка: `python make_sample_acts.py samples --count 5`, затем перетащите `samples` на `start_parser.bat`.
3. Свои акты: создайте папку `akty`, положите в неё PDF и запустите `start_parser.bat`.
4. Без bat: `python parser_local.py ПАПКА --out реестр.xlsx` (`--no-llm` — только правила).
5. Проверка блокировки сети: `python parser_local.py --selftest-network`.

## Состав

- `make_sample_acts.py`
- `parser_local.py`
- `requirements.txt`
- `start_parser.bat`
- `Инструкция.txt`

Подробная пошаговая инструкция и ограничения — в `Инструкция.txt`.
