# Локальный AI-аналитик документов

**Видео №03** канала «ByteAutomate | Код и AI» — https://t.me/ByteAutomate_AI.

Веб-интерфейс для вопросов по вашим документам: поиск по фрагментам + локальная модель через Ollama.

## Что нужно

- Windows, Python 3.9+
- Ollama (ollama.com/download)

## Быстрый запуск

1. Установите Python и Ollama.
2. Распакуйте ZIP-архив в обычную папку.
3. Дважды щёлкните `start_local_ai.bat` (модель скачается сама).
4. Откройте в браузере `http://localhost:8000`, загрузите документ и задавайте вопросы.

## Состав

- `app.py`
- `index.html`
- `rag_core.py`
- `start_local_ai.bat`
- `Инструкция.txt`

Подробная пошаговая инструкция и ограничения — в `Инструкция.txt`.

## Важно

- Набор даётся как есть, без гарантий: сначала проверьте на тестовых данных и сделайте копию своих.
- Токены, ключи и пароли в репозиторий не входят — подставляйте свои и не публикуйте их.
