# Локальная расшифровка аудио Whisper

**Видео №02** канала «ByteAutomate | Код и AI» — https://t.me/ByteAutomate_AI.

Расшифровка аудио и видео в текст и субтитры с таймкодами локально, без облака и видеокарты.

## Что нужно

- Windows, Python 3.9+ с python.org (галочка «Add python.exe to PATH»)
- Интернет при первом запуске (модель ~460 МБ)

## Быстрый запуск

1. Скачайте репозиторий (Code → Download ZIP) и распакуйте в обычную папку.
2. Перетащите аудио/видеофайл на `transcribe.bat`.
3. Дождитесь окончания: рядом с файлом появятся текст и субтитры.
4. Параметры (язык, модель): `python transcribe.py запись.mp3 --lang en --model medium`.

## Состав

- `transcribe.bat`
- `transcribe.py`
- `Инструкция.txt`

Подробная пошаговая инструкция и ограничения — в `Инструкция.txt`.

## Важно

- Набор даётся как есть, без гарантий: сначала проверьте на тестовых данных и сделайте копию своих.
- Токены, ключи и пароли в репозиторий не входят — подставляйте свои и не публикуйте их.
