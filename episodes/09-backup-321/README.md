# 09. Автобэкап данных по правилу 3-2-1

Материалы к ролику №09 канала «ByteAutomate | Код и AI» (@ByteAutomate_AI). Подробности, видео и новые материалы: канал в Telegram @ByteAutomate_AI.

## Что это

Сбой диска, случайное удаление или шифровальщик, и годы фото исчезают. Копия на том же диске копией не считается.

Правило 3-2-1: три копии, два носителя, одна вне дома. Автоматизируют его Kopia и Restic: снапшоты, дедупликация, шифрование на вашем компьютере. Бесплатны сами программы, внешний диск и облако платные.

В архиве: скрипты для Windows и Linux, конфиг, инструкция и тестовая папка.

Честно: проверено автором на Windows (Kopia 0.23.1, Restic 0.19.1), облака не проверялись. Пароль репозитория потерять нельзя, без него данные не восстановить.

## Тестовые данные

Тяжёлые тестовые файлы в репозиторий не входят (они есть в архиве подписчиков в Telegram-канале). Для проверки используйте свои файлы по описанию в `Инструкция.txt`; не включены:

- `Тестовая_папка/Фото/снимок_1.png`
- `Тестовая_папка/Фото/снимок_2.png`
- `Тестовая_папка/Фото/снимок_3.png`

## Как начать

Откройте `Инструкция.txt`: там установка, настройка, проверка и честные ограничения (что автор проверил, а что нет). Тестовые данные и примеры в наборе вымышленные.

## Важно

Набор даётся как есть, без гарантий; перед запуском на реальных данных прогоните его на примерах и сделайте вторую копию своих данных (правило 3-2-1). Сервисные ключи, токены и идентификаторы чатов в файлы не входят: подставляйте свои.
