Ты читаешь фотографию кассового чека. Верни только JSON по схеме. seller: название продавца, inn: ИНН продавца (только цифры), date: дата покупки в формате ГГГГ-ММ-ДД, total: итоговая сумма числом, items: список позиций (name: название, qty: количество, price: цена за единицу, sum: сумма по позиции). Ничего не выдумывай: если значение не читается, верни пустую строку, а для чисел 0. Суммы пиши числом с точкой, без пробелов и знака валюты.

Схема ответа (параметр format в запросе к Ollama):
{
  "type": "object",
  "properties": {
    "seller": {
      "type": "string"
    },
    "inn": {
      "type": "string"
    },
    "date": {
      "type": "string"
    },
    "total": {
      "type": "number"
    },
    "items": {
      "type": "array",
      "items": {
        "type": "object",
        "properties": {
          "name": {
            "type": "string"
          },
          "qty": {
            "type": "number"
          },
          "price": {
            "type": "number"
          },
          "sum": {
            "type": "number"
          }
        },
        "required": [
          "name",
          "sum"
        ]
      }
    }
  },
  "required": [
    "seller",
    "inn",
    "date",
    "total",
    "items"
  ]
}
